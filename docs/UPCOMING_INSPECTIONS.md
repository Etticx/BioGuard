# Upcoming inspections

BioGuard keeps restoration cases open until the follow-up findings have been reviewed by management.

## Management

1. Review the removal and replanting evidence. The actual work dates must be recorded by Ecology.
2. Accept completed restoration. This automatically creates one linked inspection for the same Ecology team.
3. The default inspection date is the actual replanting date plus 14 days. Management can change it. Delayed approval does not reset the countdown; an inspection may already be overdue.
4. Open Upcoming inspections to review scheduled and overdue inspections.
5. Review the submitted findings. Request corrections, approve further work, or close the case when no further action is required.

Replanting that is still pending does not start this post-planting follow-up. Fourteen days is a configurable demo default, not a species-specific monitoring recommendation or an SDP requirement.

## Ecology

Open Upcoming inspections and select the assigned inspection. Use the original map pin, block boundary and restoration evidence to find the location.

Record whether the target invasive plant has reappeared, the condition of replacement planting, and whether other suspected invasive plants were found nearby. Add current photos and notes; record the location of additional findings. Submit the findings to management for review.

Submitting an inspection does not close the case or authorise new removal. Management must approve corrective work. Completed corrective restoration is reviewed before its next follow-up is created.

## Existing cases

This feature applies when restoration is approved using the updated system. It does not silently create inspections for cases approved before the update. Historical photos and locations remain attached to their original reports.
